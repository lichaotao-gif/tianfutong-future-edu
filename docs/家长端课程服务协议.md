# 天府未来教育中心 · 课程服务协议（家长端）


---

## 特别提示

**本协议的相对方是为您孩子实际授课的服务机构，不是平台。** 平台负责课程展示、交易与资金管理、上课记录留存与售后协调，不提供教学。

**请在勾选同意前完整阅读本协议，特别是加粗与标 ▲ 的条款：资金存管与结算、课时确认与自动确认、退费规则、责任划分。勾选同意或实际使用服务，即视为您接受本协议全部内容。**

**本协议仅面向具备完全民事行为能力的家长或其他法定监护人，未成年人不得自行注册。**

## 一、协议主体与平台角色

**1.1 ▲ 本协议的双方**

- **甲方（服务机构）：** 为您所报名班次实际提供教学服务的机构，**具体名称、统一社会信用代码以您报名时页面展示及订单记录为准**。
- **乙方（您）：** 为子女或被监护人报名课后服务课程的家长或其他法定监护人。

**您就同一账号下不同课程分别报名的，分别与各自的服务机构成立独立的课程服务协议。**

**1.2 ▲ 平台是谁、做什么**

「天府未来教育中心」是**天府通平台内的课后服务板块**（以下称“平台”），由**天府通**运营，为本协议的订立与履行提供技术与交易服务。天府通委托 **四川萃雅教育科技有限公司** 承担平台的日常技术与运营工作。

**您与平台之间的账号注册、平台使用规则等事项，适用天府通的《平台服务协议》与《隐私政策》。**

| 平台负责 | 平台不负责 |
|---|---|
| 机构与教师资质审核、课程审核与发布 | 教学内容与教学质量 |
| 课程展示、报名与订单管理 | 师资安排 |
| 交易与资金存管、分账结算 | 教学过程中的安全保障 |
| 上课记录与考勤留存 | 场地安全 |
| 售后协调与争议处理 | |

**1.3 ▲ 平台不是本协议当事方。** 课程服务由甲方提供并承担责任；平台按本协议约定的规则执行交易、资金与记录管理。您就教学质量、上课安排、退费等事项，可向甲方提出，也可通过平台售后渠道提交，由平台协调处理。

**1.4 几个常用词**

| 词 | 含义 |
|---|---|
| 班次 | 同一课程下按固定时间、地点、师资划分的开课单元，**您报名的是具体班次** |
| 成班人数 | 开班所需的最低报名人数 |
| 课时确认（销课） | 每节课后由您确认该节课的教学服务是否按约提供 |

## 二、报名主体与学生信息

> 账号注册、登录方式、账号安全与平台使用规则，适用天府通的《平台服务协议》，本协议不再重复约定。

**2.1** 您需为所报名学生的父母或其他法定监护人。学生的**就读学校须从平台合作学校名单中选择**，不支持手填；一个账号可添加多名学生并分别报名。

**2.2 ▲** **您承诺所填学生信息真实、准确，且您对该学生依法享有监护权。因信息不实导致无法上课或产生其他后果的，由您承担。**

**2.3 ▲** **通过您账号完成的报名、支付、课时确认等操作，就本协议而言视为您本人行为**，但有充分证据证明系系统故障或他人非法侵入且您无过错的除外。

## 三、课程展示与报名

**3.1** 平台按学生就读学校展示可报名课程：校内课程仅对本校学生开放，校外点位课程可面向周边学校学生开放。课程的时间、地点、师资、课时数、价格、成班人数与报名截止时间，由甲方提供、经平台审核后发布。请在公示的报名时段内完成报名与支付，**班次名额有限，报满即止**。

**3.2** **同一学生不得报名时间冲突的多个班次。** 系统会提示冲突，您仍选择继续的，由此导致无法正常上课的后果由您承担。

**3.3 ▲** **报名成功不等于开班成功**，实际开班以达到成班人数为前提，详见第五条。

## 四、支付与资金存管

**4.1** 课程费用通过平台接入的**通联支付网络服务股份有限公司**（持牌支付机构，以下称“通联支付”）收款通道一次性支付，以报名时页面显示的班次价格为准。

**4.2** **支付由通联支付按其规则处理。因支付通道、银行或您所选支付工具原因导致支付失败、重复支付、到账延迟的，由通联支付及相应机构按其规则处理，平台将协助查询，但不承担该等第三方原因造成的责任。**

**4.3 ▲ 资金怎么走**

1. 您支付的课程费用**不即时支付给甲方**，而是进入通联支付的监管账户存管；
2. 甲方须在通联支付开立收款子账户方可上线课程；
3. **每节课经确认后**（见第六条），该节课费用才进入可结算范围，按月按约定规则完成分账结算；
4. **未实际完成的课时费用继续存管，不予结算**；课程终止或退费按第五、七条处理。

**4.4** 分账、退款指令按本协议约定的销课与结算规则发起；**通联支付依指令及其业务规则执行，不介入课程服务争议**。

**4.5** 课程服务发票由**甲方**向您开具，可通过平台客服协助联系。

## 五、成班与开课

**5.1 ▲ 没凑够人数怎么办** **报名截止仍未达到最低成班人数的，该班次取消，将在 5 个工作日内按原渠道全额退款**并通知您。也可能与您协商延长报名时间或推荐同类课程，**须经您明确同意**；推荐新课程**采用“先退款、后重新支付”办理，不做费用平移**。**您不同意替代方案的，全额退款。**

**5.2** 上课教室与时间由平台与学校（或校外点位运营方）协调确定后展示。

**5.3 ▲ 可能发生的调整**

| 情形 | 处理 |
|---|---|
| 学校教学安排、场地调整、公共卫生事件、极端天气、主管部门要求等 | 课程可能顺延、调时间或调地点，提前通知您，**优先通过补课、调课保障您已付课时权益** |
| **课程调整**：不减少总课时、不降低课程质量前提下调整具体日期、时段、教室 | 通知您后执行。**属正常履行范围，不构成违约，不因此产生退费权利** |
| **师资变更**：教师离职、休假、病假等 | 由甲方安排**同等资质**教师接替并通知您。**不构成退费理由** |
| **班次合并**：人数偏少但已达成班人数的相邻班次 | **须征得您同意**；您不同意的，按第七条退费 |

## 六、上课、考勤与课时确认 ▲

**6.1** 每节课由甲方授课教师在系统记录考勤（已到 / 缺勤）并提交课堂记录，您可在家长端查看。

**6.2 逐节确认** 每节课后系统生成确认任务，您可在“学习成果”中逐节确认。**您确认的是该节课的教学服务是否按约提供。确认后该节课费用进入可结算范围。**

**6.3 ▲ 自动确认** **确认任务生成后 3 个自然日内您未确认、也未提出异议的，视为您已确认该节课的教学服务已按约提供，费用自动进入可结算范围。**

**6.4 ▲ 有异议怎么办** 对某节课有异议（该节课未实际开展、考勤与实际不符等），可在确认期限内点“有异议”并选择原因提交，**该课时暂停计入结算**，由平台核实。

**6.5 ▲** **平台基于考勤记录、课堂记录、教师签到、学校反馈等佐证材料核实。** 异议属实的，该节课不计入结算并按实际情况处理；**不属实的，向您说明后恢复确认、正常计入结算**。**您对核实结论仍有异议的，可通过客服申诉，或依法向有关部门投诉、向人民法院起诉。**

**6.6 ▲** **超过确认期限既未确认也未提异议的，视为您认可该节课已按约提供，事后不得再就该节课主张退费**，但有证据证明该节课确未开展的除外。

**6.7 ▲ 孩子没去上课** **因个人原因（含请假、事假、病假）缺课的，该节课视为甲方已按安排提供服务，课时正常计入结算，甲方不承担退费义务**，甲方自愿补课的除外。**因甲方原因（教师缺勤、无故停课）未实际开展的，该节课不计入结算**，由甲方安排补课或按第七条退费。

## 七、退费 ▲

**7.1 可以退的情形**

| 情形 | 退费 |
|---|---|
| 未达成班人数，课程取消 | **全额退款** |
| 开课前您主动取消报名（开课日前 3 日 24:00 前申请） | **全额退款** |
| 甲方原因导致课程无法继续（机构退出、无法配备教师、被责令停止办学等） | 按未消耗课时比例退还 |
| 课程实际内容与公示信息存在实质性不符，经核实属实 | 按未消耗课时比例退还 |
| 法律法规规定的其他应退情形 | 依法办理 |

**7.2 怎么算** **已完成并确认的课时费用不退**；未消耗课时按“课程总价 ÷ 总课次 × 剩余课次”退还，原路返回原支付账户，到账时间以支付渠道与银行时效为准。

**7.3 ▲ 学生个人原因中途退出**（转学、搬迁、身体原因、时间冲突等非归责于甲方的原因）

- 已完成及**已自动确认**的课时费用不退；
- 剩余课时费用**扣除已发生的必要成本后退还**（已采购的教材教具、已发生的场地与师资预留成本、支付通道手续费）；
- **已完成课次超过总课次 50% 的，剩余费用不退**，甲方自愿补偿的除外；
- **须在结课日前提出，结课后不再受理**；
- 核实后 15 个工作日内办理。

**7.4 ▲ 退费由谁付** **退费义务由甲方承担。** 应退款项**优先从通联支付存管账户中尚未结算给甲方的资金中扣划**；不足部分由甲方补足。**甲方未按期补足的，平台可从其后续应结算款项中扣划。**

## 八、个人信息

处理您与学生的个人信息依照《个人信息保护法》《儿童个人信息网络保护规定》等法律法规执行。**学生多为不满十四周岁的儿童，其信息属敏感个人信息，采取更严格的保护措施。**

**信息仅用于报名、考勤、教学记录、结算与售后，不用于画像、营销或对外出售。** 收集清单、共享范围、存储期限与您的权利详见《隐私政策》（含儿童个人信息专章）。

## 十、责任划分 ▲

**10.1 谁负责什么**

| 方 | 责任 |
|---|---|
| **甲方（服务机构）** | **教学内容、质量、效果、师资安排及教学过程中的安全保障义务，由甲方独立承担。因甲方或其教师原因造成您或学生人身、财产损害的，由甲方依法承担赔偿责任。** |
| **学校 / 场地方** | **场地设施与消防安全、校园秩序管理由其依职责负责。** |
| **您（监护人）** | **自课程结束、授课教师完成学生交接后，学生的安全由您负责。** |
| **平台** | 资质形式审核、课程信息审核发布、交易与资金流转管理、教学记录留存、售后协调。 |

**10.2 ▲ 审核的性质** **平台对甲方的审核为形式审核**（资质证照、备案信息的完整性与表面真实性核验），**不构成对其教学质量、教学效果、学生学习成果或持续经营能力的担保。**

**10.3 免责情形** **因下列原因导致课程中断、延迟或无法提供的，甲方与平台不承担违约责任，但将积极协调并保障您的已付费权益：** 不可抗力；支付通道、电信运营商、云服务商等第三方故障；学校因教学安排或校园管理作出的调整；主管部门政策调整；您自身设备、网络原因或操作不当。

## 十一、协议变更、终止与争议解决

**11.1 协议修订** 本协议文本由平台统一提供并可能修订。**修订内容在生效前 7 日通过平台公告、消息推送等方式通知您。修订生效后您新报名课程的，适用修订后文本；已报名未完成的课程仍适用您报名时的文本，您不同意修订内容的，可按第七条申请退费。**

**11.2 账号注销与本协议的关系** 账号注销规则见《平台服务协议》。**注销前请先完成已报名课程的相关事宜（含退费申请）；已报名未完成的课程不因账号注销而自动退费。**

**11.3 争议解决** 本协议适用**中华人民共和国法律**（不含港澳台地区法律）。争议双方应友好协商；协商不成的，任一方可依法向有管辖权的人民法院提起诉讼。

**11.4 其他** 部分条款被认定无效，不影响其他条款效力。本协议与《隐私政策》共同构成完整约定，**冲突时以对您更有利的约定为准**。本协议自您勾选同意之日起、就您所报名的具体班次在您与该班次的服务机构之间生效。

**11.5 联系我们** 请通过家长端“我的—客服与售后”提交咨询、投诉与退费申请，将在 3 个工作日内响应。客服电话、邮箱与服务时间以该页面公示为准。
