| **天府未来教育中心** | **天府通平台内的课后服务板块名称**，萃雅经授权在该板块内运营。不是公司 | 否（不是主体） |

**合同关系：** 家长↔萃雅（用户协议）｜萃雅↔天府通（渠道协议 ＋ **板块名称使用授权**）｜家长↔机构（**待定，见 A1**）｜萃雅↔机构（入驻协议＋DPA）｜萃雅↔通联（支付协议）｜机构↔通联（子账户开户）｜萃雅↔学校（进校协议，**待确认是否存在**）

**资金路径：** 家长 → 通联（萃雅监管账户存管）→ 逐节确认后按月分账 → 机构子账户及其他合作方。**款项不经萃雅自有账户。**

## A. 需要你拍板（不依赖外部）

| # | 事项 | 说明 | 状态 |
|---|---|---|---|
| **A0** | **天府通是渠道，还是平台经营者？** | “天府未来教育中心”是天府通侧的板块名称，家长在天府通 App 内、用天府通的品牌买课，很可能被认定为天府通是平台经营者、萃雅是平台内经营者。**这会反转资质审核义务与连带责任的归属。**须在《渠道合作协议》中明确，不能只在家长协议里单方面写“天府通不担责” | 🔴 ⬜ |
| **A1** | **家长买课，卖方是机构还是我们？** | 撮合模式（补一条“报名成功即与机构成立课程服务合同”，§10 免责才成立）／自营转售（§10 要重写、发票改我们开）。**协议骨架，定错全返工** | 🔴 ⬜ |
| **A2** | 分账明细是否向家长披露 | **已定：不披露。** §1.4、§4.3 已改为中性表述，不提方数与比例，也不再暗示款项全额给机构 | ✅ 已定 |
| **A3** | 销课确认的含义 | 家长确认的是“孩子上了课”还是“机构按约开了课”？现定义写前者、规则按后者。建议改定义为“教学服务是否按约提供”，产品文案同步 | 🔴 ⬜ |
| **A4** | 自动确认要不要加兜底 | 连续 3 节自动确认时主动电话/短信核实并留痕。挡的是“两周没看 App、一分不退”这类舆情场景 | 🔴 ⬜ |
| **A5** | 「课时」还是「课次」 | 退费公式写“总课时数”，产品写“共 8 次课”。一次课若含 2 课时，退费差一倍。建议全文统一为“课次” | ⬜ |
| **A6** | 校外课程是否限合作学校学生 | §2.1 要求学校从合作名单选，§3.1 说校外课程面向“周边学校”——非合作学校家长根本注册不了 | ⬜ |
| **A7** | 地方平台、学校的定位 | 是单纯分成方，还是共同运营方？决定出纠纷时他们是否能脱身 | ⬜ |
| **A8** | 入口页加主体标识 | 首屏加“本服务由四川萃雅教育科技有限公司提供”。**性价比最高的一个动作**，直接支撑 §1.3 天府通免责 | ⬜ |

## C. 需要法务定稿（可与 A、B 并行）

| # | 条款 | 问题 |
|---|---|---|
| **C1** | §7.3 退费扣减 | 🔴 “必要成本扣减”“超过 __% 不退”“结课后不受理”均为不利格式条款，须评估合法边界并核对 B1 的监管口径 |
| **C2** | §10 责任限制 | 🔴 “不承担连带责任”“赔偿上限”“间接损失免责”——《消保法》《电商法》有平台连带责任的强制规定，过度免责有整体无效风险 |
| **C3** | §6.5 判定权 | 加一句“仍有异议可申诉或依法投诉、起诉”。**加了反而更容易被认可**，因为不再是终局排除 |
| **C4** | §9.3 单方抵销 | “自待退款项中直接扣除”范围过宽，建议限定为经书面确认或生效裁判确定的金额 |
| **C5** | §10.1 安全交接点 | “上下学途中由监护人负责”——孩子放学后留校上课，课后到出校门这段谁负责？须明确交接节点 |
| **C6** | §7.1 规则真空 | “开课前 ___ 前申请全额退”，该时点后至开课前如何处理，无规则 |
| **C7** | §5.1 无期限 | 未成班可“延长报名”，但没写最长等多久，家长资金可能被无限期占用 |
| **C8** | §6.3 自动确认 3 日 | 期限合理性与提示义务是否充分 |
| **C9** | §8 明示同意 | 以行为推定“明示同意”偏弱，须与产品实际交互对齐后定措辞 |
| **C10** | 隐私 §4.9 | 收集时不核验监护关系、行权时才核验，逻辑不对称，可能被质疑同意有效性 |
| **C11** | 格式条款提示义务 | 《民法典》496 条要求对免责限责条款合理提示说明 |
| **C12** | DPA 缺失 | 隐私政策已向家长承诺对机构的约束措施，**但数据处理协议尚未签署**，承诺无对应义务支撑 |
