## 三、课程展示与报名

**3.1** 我们按学生就读学校展示可报名课程：校内课程仅对本校学生开放，校外点位课程可面向周边学校学生开放。课程的时间、地点、师资、课时数、价格、成班人数与报名截止时间，由服务机构提供、经我们审核后发布。请在公示的报名时段内完成报名与支付，**班次名额有限，报满即止**。

**3.2** **同一学生不得报名时间冲突的多个班次。** 系统会提示冲突，您仍选择继续的，由此导致无法正常上课的后果由您承担。

**3.3 ▲** **报名成功不等于开班成功**，实际开班以达到成班人数为前提，详见第五条。

## 四、支付与资金存管

**4.1** 课程费用通过通联支付通道一次性支付，以报名时页面显示的班次价格为准（同一课程在不同学校、不同班次价格可能不同）。

**4.2** **支付由通联支付按其规则处理。因支付通道、银行或您所选支付工具原因导致支付失败、重复支付、到账延迟的，由通联支付及相应机构按其规则处理，我们将协助查询，但不承担该等第三方原因造成的责任。**

**4.3 ▲ 资金怎么走**

1. 您支付的费用**不直接给服务机构**，而是进入我们在通联支付开立的监管账户存管；
2. 服务机构须在通联支付开立收款子账户才能入驻，**未开户的机构课程不予上线**；
3. **每节课经确认后**（见第六条），该节课费用才计入服务机构应结算金额，我们按月发起分账划付；
4. **未实际完成的课时费用继续存管，不予结算**；课程终止或退费按第五、七条处理。

**4.4** 我们按本协议的销课与结算规则向通联支付发起分账、退款指令；**通联支付依指令及其业务规则执行，不介入课程服务争议**。存管资金孳息（如有）依我们与通联支付的约定及法律规定处理。

**4.5** 课程服务发票由**实际授课的服务机构**开具，可通过客服协助联系。

## 五、成班与开课

**5.1 ▲ 没凑够人数怎么办** **报名截止仍未达到最低成班人数的，该班次取消，我们在 ___ 个工作日内按原渠道全额退款**并通知您。我们也可能与您协商延长报名时间或推荐同类课程，**须经您明确同意**；推荐新课程**采用“先退款、后重新支付”办理，不做费用平移**。**您不同意替代方案的，全额退款。**

**5.2** 上课教室与时间由我们与学校（或校外点位运营方）协调确定后在平台展示。

**5.3 ▲ 可能发生的调整**

| 情形 | 处理 |
|---|---|
| 学校教学安排、场地调整、公共卫生事件、极端天气、主管部门要求等 | 课程可能顺延、调时间或调地点，我们提前通知，**优先通过补课、调课保障您已付课时权益** |
| **课程调整**：不减少总课时、不降低课程质量前提下调整具体日期、时段、教室 | 通知您后执行。**属正常履行范围，不构成违约，不因此产生退费权利** |
| **师资变更**：教师离职、休假、病假等 | 由机构安排**同等资质**教师接替并通知您。**不构成退费理由** |

## 六、上课、考勤与课时确认 ▲

**6.1** 每节课由授课教师在系统记录考勤（已到 / 缺勤）并提交课堂记录，您可在家长端查看。

**6.2 逐节确认** 每节课后系统生成确认任务，您可在“学习成果”中逐节确认。**确认后该节课费用进入可结算范围。**

**6.3 ▲ 自动确认** **确认任务生成后 3 个自然日内您未确认、也未提出异议的，视为您已确认该节课完成，费用自动进入可结算范围。**

**6.4 ▲ 有异议怎么办** 对某节课有异议（孩子当日未上课、该节课未开展、考勤与实际不符等），可在确认期限内点“有异议”并选择原因提交，**该课时暂停计入结算**，由我们核实。

**6.5 ▲** **我们基于考勤记录、课堂记录、教师签到、学校反馈等佐证材料核实，核实结论以本平台判定为准。** 异议属实的，该节课不计入结算并按实际情况处理；**不属实的，向您说明后恢复确认、正常计入结算**。**多次提交经核实不属实的异议，我们可限制您的异议功能。**

**6.6 ▲** **超过确认期限既未确认也未提异议的，视为您认可该节课已按约完成，事后不得再就该节课主张退费**，但有证据证明该节课确未开展的除外。

**6.7 ▲ 孩子没去上课** **因个人原因（含请假、事假、病假）缺课的，该节课视为已按安排提供服务，课时正常计入结算，我们与服务机构不承担退费义务**，机构自愿补课的除外。**因机构原因（教师缺勤、无故停课）未实际开展的，该节课不计入结算**，我们协调补课或按第七条退费。

## 七、退费 ▲

**7.1 可以退的情形**

| 情形 | 退费 |
|---|---|
| 未达成班人数，课程取消 | **全额退款** |
| 开课前您主动取消报名（______ 前申请） | **全额退款** |
| 服务机构原因导致课程无法继续（机构退出、无法配备教师、被责令停止办学等） | 按未消耗课时比例退还 |
| 课程实际内容与公示信息存在实质性不符，经核实属实 | 按未消耗课时比例退还 |
| 法律法规规定的其他应退情形 | 依法办理 |

**7.2 怎么算** **已完成并确认的课时费用不退**；未消耗课时按“课程总价 ÷ 总课时数 × 剩余课时数”退还，原路返回原支付账户，到账时间以支付渠道与银行时效为准。

**7.3 ▲ 学生个人原因中途退出**（转学、搬迁、身体原因、时间冲突等非归责于我们和服务机构的原因）

- 已完成及**已自动确认**的课时费用不退；
- 剩余课时费用**扣除已发生的必要成本后退还**（已采购的教材教具、已发生的场地与师资预留成本、支付通道手续费）；
- **已完成课时超过总课时 ____% 的，剩余费用不退**，机构自愿补偿的除外；
- **须在结课日前提出，结课后不再受理**；
- 核实后 ___ 个工作日内办理，扣减金额以平台核算结果为准。

## ⚠️ 法务定稿前须重点确认

1. **§7.3 退费扣减**——“必要成本扣减”“超过 ____% 不退”“结课后不受理”均属对消费者不利的格式条款，须评估合法性边界，并核对**校外培训预收费监管、退费时限**等强制性规定。**地方监管更严的，以监管规定为准。**
2. **§10 责任限制**——“不承担连带责任”“赔偿上限”“间接损失免责”须评估可执行边界。**《消费者权益保护法》《电子商务法》规定平台明知或应知经营者侵害消费者权益未采取必要措施的依法承担连带责任**，过度免责有被整体认定无效的风险。
3. **§6.3 自动确认 3 日**——须确认期限设置的合理性与提示义务是否充分。
4. **格式条款提示义务**——《民法典》第 496 条要求对免责、限责条款以合理方式提示说明，建议在注册页对 ▲ 条款作单独提示并留存同意日志。
5. **待补内容**——统一社会信用代码、客服电话与地址、各处空白时限与比例；与天府通（渠道）、通联支付（资金）的合作协议表述需与本协议一致。
