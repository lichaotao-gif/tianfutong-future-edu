## 三、请法务重点核对的条款

1. **🔴 课程服务协议 §7.3 退费扣减**——“必要成本扣减”“已完成课次超过 50% 不退”“结课后不受理”均属对消费者不利的格式条款。**50% 这个阈值是业务侧的估值，没有法律依据支撑**，须核对校外培训预收费与退费的监管口径；地方监管更严的，以监管规定为准。

2. **🔴 平台服务协议 §7.3 平台责任**——采用正面表述（依法履行平台经营者义务、未尽义务依法担责），未作过度免除。须由天府通法务确认其愿意承担的边界，并核对《电子商务法》《消费者权益保护法》的强制性规定。

3. **课程服务协议 §6.3 自动确认 3 日**——期限合理性与提示是否充分。

4. **课程服务协议 §6.6 + §7.3 的叠加效果**——超期未确认不得主张退费 + 已自动确认不退，两条叠加可能出现“长期未查看即全额不退”。业务侧建议增加兜底（连续 3 节自动确认时主动核实并留痕），尚未落地。

5. **格式条款的提示义务**——《民法典》第 496 条要求对免责、限责条款以合理方式提示说明。文本内已用加粗与 ▲ 标注，产品侧是否需要额外提示，请一并评估。
