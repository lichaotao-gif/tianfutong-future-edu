# 天府未来教育中心 · 平台服务协议（家长端）


---

## 特别提示

**本协议约定的是您与天府通之间的账号与平台使用关系。您报名的课程由服务机构提供，课程本身的报名、付费、上课、退费等事项，适用您与该机构签订的《课程服务协议》。**

**请在勾选同意前完整阅读，特别是加粗与标 ▲ 的条款：账号规则、平台服务边界、违规处置、责任划分。**

**本协议仅面向具备完全民事行为能力的家长或其他法定监护人，未成年人不得自行注册。**

## 一、我们是谁

**1.1** 本协议的相对方为 **天府通**（运营主体及统一社会信用代码以平台公示的主体信息为准，以下称“我们”或“平台”）。

**1.2** 「天府未来教育中心」是天府通平台内的**课后服务板块**。我们委托 **四川萃雅教育科技有限公司** 承担该板块的日常技术与运营工作；**受托方在委托范围内提供服务，相关行为的对外责任由我们承担。**

**1.3 ▲ 平台做什么、不做什么**

| 我们负责 | 我们不负责 |
|---|---|
| 服务机构与教师的资质审核 | 教学内容与教学质量 |
| 课程信息的审核与发布 | 师资安排与教学效果 |
| 课程展示、报名与订单管理 | 教学过程中的安全保障 |
| 交易与资金存管、分账结算 | 场地设施与消防安全 |
| 上课记录与考勤留存 | |
| 售后协调与争议处理 | |

**1.4 ▲** **课程服务由服务机构提供，您与服务机构之间成立《课程服务协议》。** 我们不是该协议的当事方，但依法履行平台经营者的审核、公示、记录留存、协助维权与必要措施义务。

## 二、账号

**2.1 注册与登录** 您可通过天府通账号授权登录，或以手机号验证码方式注册。

**2.2 ▲ 一人一号** 账号仅限您本人使用，**不得出借、转让、出售或以任何方式交由他人使用**。

**2.3 ▲ 账号安全** 请妥善保管账号与验证码。**通过您账号完成的操作（包括添加学生、报名、支付、课时确认等）均视为您本人行为，由此产生的后果由您承担**，但有充分证据证明系我们的系统故障或他人非法侵入且您无过错的除外。发现账号异常，请立即通过客服渠道通知我们。

**2.4 学生信息** 您需为所添加学生的父母或其他法定监护人。**学生的就读学校须从平台合作学校名单中选择**，一个账号可添加多名学生。学生信息的具体处理规则见《隐私政策》。

**2.5 账号注销** 您可随时申请注销账号。**注销前请先完成已报名课程的相关事宜（含退费申请）；已报名未完成的课程不因账号注销而自动退费。** 注销后账号不可恢复，您将无法查询历史订单与教学记录；相关数据按《隐私政策》与法律规定处理。

## 三、平台规则

**3.1** 使用本平台时，请不要实施以下行为：

(a) 提供虚假学生信息，或冒用他人身份注册、报名；
(b) 恶意占用报名名额、批量注册账号、使用外挂或自动化工具抢课；
(c) **提交明知不实的课时异议，骗取退款**；
(d) 干扰平台正常运行，或侵害其他用户、服务机构、学校的合法权益；
(e) 发布违法、侵权或违背公序良俗的内容；
(f) 违反法律法规的其他行为。

**3.2 ▲ 违规处置** 您违反上述规则的，我们可根据行为性质与严重程度采取以下一项或多项措施：

| 程度 | 措施 |
|---|---|
| 轻微 | 提示、警示 |
| 一般 | 限制或关闭部分功能（如报名、异议提交） |
| 严重 | 暂停账号 |
| 特别严重或屡次违规 | 终止服务并注销账号 |

**采取限制功能及以上措施的，我们将同时告知您原因与依据。**

**3.3 ▲ 申诉** **您对处置措施有异议的，可通过客服渠道申诉，我们将在 5 个工作日内复核并告知结果。** 您对复核结果仍有异议的，可依法向有关部门投诉或向人民法院起诉。

**3.4** **处置措施不影响您已报名课程项下的既有权利。** 因处置导致课程无法继续的，按《课程服务协议》第七条处理费用。

**4.1** 我们按现有技术与条件提供平台服务，并持续改进。

**4.2 ▲ 服务中断** **因下列原因导致平台服务中断、延迟或无法使用的，我们不承担违约责任，但将及时公告并尽力恢复，且不影响您已支付课程的权益：** 不可抗力；系统维护与升级（将提前公告）；支付通道、电信运营商、云服务商等第三方故障；您自身设备、网络原因或操作不当；法律法规或主管部门要求。

**4.3 服务调整** 我们可对平台功能进行调整、增加或下线。**涉及您已报名课程权益的重大调整，我们将提前 7 日公告。**

## 五、个人信息

**5.1** 我们依《个人信息保护法》《儿童个人信息网络保护规定》等法律法规处理您与学生的个人信息，**我们是个人信息处理者**，四川萃雅教育科技有限公司为受托处理方。

**5.2** **本平台服务的学生多为不满十四周岁的儿童，其个人信息属于敏感个人信息，我们采取更严格的保护措施；不用于画像、营销或对外出售。**

**5.3** 收集范围、使用目的、共享对象、存储期限与您的权利，详见《隐私政策》（含儿童个人信息专章）。**您的个人信息相关请求向我们提出，由我们统一受理并协调相关方处理。**

## 七、责任划分 ▲

**7.1 平台的审核** **我们对服务机构与教师的审核为形式审核**（资质证照、备案信息的完整性与表面真实性核验）。**该审核不构成对其教学质量、教学效果或学生学习成果的担保。**

**7.2 ▲ 教学与场地责任** **教学内容、质量、师资安排及教学过程中的安全保障，由服务机构承担；场地设施与消防安全、校园秩序管理，由学校或场地运营方依其职责承担。** 前述主体的责任，依《课程服务协议》及相关法律确定。

**7.3 ▲ 我们依法承担的责任** **我们依法履行平台经营者义务，包括资质审核、信息公示、交易与资金安全保障、记录留存、投诉处理，以及在知悉服务机构侵害您合法权益时及时采取必要措施。因我们未尽上述义务给您造成损失的，我们依法承担相应责任。**

**7.4** 我们将协助您向服务机构主张权利，包括提供该机构的名称、统一社会信用代码、联系方式及相关交易与教学记录。

**8.3** 本协议部分条款被认定无效，不影响其他条款效力。**本协议与《隐私政策》共同构成您与我们之间的完整约定；与《课程服务协议》的关系见 1.4。**

**8.4 联系我们** 请通过家长端“我的—客服与售后”提交咨询、投诉与申诉，我们将在 3 个工作日内响应。客服电话、邮箱与服务时间以该页面公示为准。
