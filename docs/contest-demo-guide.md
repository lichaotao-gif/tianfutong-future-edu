# 赛事 Demo 演示说明

## 状态样例

后台“赛事评审中心”里的“状态演示”赛事覆盖：草稿、未开始、报名中、报名结束、评审中、等待结果公布、结果已发布、已归档。
日期仅作展示，前端报名入口由后台选择的状态决定。
家长端“我的参赛”可查看资格待审、资格不通过（含原因）、待评分、评分中、待复核、结果已确定、获奖和未获奖样例。
草稿不在活动列表出现；归档赛事不出现在活动列表，但参赛记录保留。

## 完整演示路径

1. 家长端进入“状态演示 · 报名中”，给尚未报名的李晨曦提交作品。该样例仅支持团队，填写团队名称、成员和作品说明，上传一项材料。
2. 后台进入同一赛事的“参赛作品”，审核新作品资格，通过后指定专家。
3. 在“评审链接”打开王思远的专属页面，评分可先暂存，再填写全部维度与评语后提交。
4. 后台“查看结果”进入复核，选择来自赛事配置的奖项，填写复核意见并确认。也可以退回专家重评。
5. 完成该赛事其余待审、待评作品后发布结果。家长端将显示奖项；发布前只提示等待统一公布。
6. 如需直接演示发布，使用“状态演示 · 等待结果公布”，其评分和复核已完成。

## 配置和文件

- 编辑赛事：基础信息、前端展示内容、报名与材料三个分区，保存时检查全部分区。
- 奖项可配置名称、奖杯／奖章／星星图标和名额说明；名额不作配额限制。
- 赛程使用可增删、上移的节点；赛事日期使用日期选择器。
- 附件类型和个人／团队配置同步影响家长端报名。
- 列表封面、图集和宣传片封面可上传预览；赛事附件和宣传片文件保存在同源浏览器的 IndexedDB，不上传服务器。清理浏览器数据或换设备后需重新选择文件。
- 内置宣传片是明确标注的演示动画；内置附件下载为明确标注的 TXT 示例，不冒充原始 PDF。
- 后台“预览”查看已保存的家长端页面；草稿与归档在预览模式也可见。
- 评分规则独立维护，已有评分后修改会提醒，但 Demo 不提供规则版本管理。

## 检查

运行 `npm test` 和 `npm run build`。静态自动检查之外，仍需浏览器验证文件选择、媒体播放和跨页评审流程。
