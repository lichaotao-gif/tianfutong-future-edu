# 天府未来教育中心 · 隐私政策（家长端）


---

## 引言

「天府未来教育中心」是天府通平台内的课后服务板块（以下称“本平台”）。本平台由**天府通**运营并承担个人信息处理者责任，日常技术与运营工作由其委托的 **四川萃雅教育科技有限公司** 承担。本政策说明本平台如何收集、使用、共享、存储和保护您与您子女（或被监护人）的个人信息，以及您享有的权利。

**请重点阅读加粗条款。勾选同意或继续使用服务，即表示您理解并同意本政策。**

**【儿童信息提示】本平台服务涉及不满十四周岁未成年人的个人信息。您作为监护人同意本政策，即视为授权按本政策处理该未成年人的个人信息。**

**【本政策与两份协议的关系】** 您与**天府通**之间的账号与平台使用关系，适用《平台服务协议》；您与**服务机构**之间的课程服务关系，适用《课程服务协议》。本政策适用于上述全部环节中的个人信息处理。服务机构为履行课程协议所必需而处理学生信息的行为，由服务机构依法负责。

## 〇、涉及您个人信息的各方

| 方 | 角色 | 与您个人信息的关系 |
|---|---|---|
| **天府通** | **平台经营者，本政策的发布主体与个人信息处理者** | 决定处理目的与方式，对您承担个人信息保护责任 |
| **四川萃雅教育科技有限公司** | **受天府通委托的运营方（受托处理者）** | 按委托范围运营平台系统、执行信息的收集、存储与安全保障。**不得超出委托范围处理，不自行决定处理目的** |
| **服务机构及授课教师** | 您的课程服务合同相对方 | 为履行课程合同处理学生信息（教师仅限本人所授班级） |
| **通联支付** | 持牌支付机构 | 处理订单与支付信息。**不获取学生姓名与教学记录** |
| **学校** | 场地提供与在校管理 | 只读查看本校学生的报名与出勤情况 |
| **教育行政主管部门** | 监管 | 接收依法报送的数据 |

> **您的权利向天府通主张。** 四川萃雅教育科技有限公司按委托协议提供运营支持，其处理行为的对外责任由天府通承担；萃雅在委托范围内对天府通负责。

## 一、我们收集哪些信息

**1.1 您主动提供的**

| 场景 | 信息 | 用途 | 是否必需 |
|---|---|---|---|
| 注册登录 | 手机号、短信验证码 | 创建账号、身份验证 | **必需** |
| 天府通授权登录 | 天府通开放标识、昵称、头像 | 快捷登录、账号关联 | 选此方式时必需 |
| 添加学生 | **学生姓名、就读学校、年级班级** | 匹配可报名课程、报名与考勤管理 | **必需** |
| 报名支付 | 订单信息、支付渠道流水号 | 完成交易、资金存管与结算 | **必需** |
| 售后申请 | 问题描述、联系方式、您上传的凭证 | 处理售后诉求 | 申请时必需 |
| 完善资料 / 课程评价 | 昵称、头像、评价内容 | 个性化展示、服务改进 | 非必需 |

**1.2 服务过程中产生的**

| 类型 | 内容 | 用途 |
|---|---|---|
| 教学过程信息 | **学生考勤（已到 / 缺勤）、课堂记录、教师评语** | 教学管理、课时确认、销课结算依据 |
| 交易信息 | 订单状态、课时确认记录、退费记录 | 交易履行与争议处理 |
| 设备与日志 | 设备型号、系统、IP、访问时间、操作日志 | 服务安全、故障排查、防范作弊与恶意行为 |

**1.3 从第三方获取** 您通过天府通账号登录的，按您的授权获取必要账号信息；**服务机构教师录入的学生考勤与课堂记录，由服务机构提供至平台系统**。

**1.4 我们不收集** **学生的身份证号、生物识别信息、家庭住址、健康医疗信息**（您在售后中主动提供的除外），**不收集您的通讯录、短信、相册**（您主动上传凭证的除外）。

## 二、我们如何使用

**2.1** 信息仅用于：提供课程展示、报名、支付、上课管理与课时确认；按就读学校匹配课程范围；生成销课记录并完成结算；处理售后、投诉与退费；发送服务通知（上课提醒、待确认提醒、退费通知等）；保障账号与交易安全，识别虚假报名、恶意异议、批量抢占名额等异常行为；按法律法规与主管部门要求报送数据；在**去标识化、汇总统计**前提下用于服务改进。

**2.2** **超出上述范围使用，将再次征得您的同意。**

**2.3** **不会将学生个人信息用于商业广告推送、精准营销或对外出售。** 服务通知不属于商业营销信息。

## 三、我们如何共享

**3.1** **除下表情形及法律法规规定外，不向任何第三方共享您与学生的个人信息。** 共享遵循最小必要原则，并要求接收方按不低于本政策的标准保护信息。

| 接收方 | 共享内容 | 目的与依据 |
|---|---|---|
| **服务机构及授课教师** | 学生姓名、年级班级、报名班次、考勤与课堂记录 | **履行您与服务机构之间《课程服务协议》所必需**：教学组织、点名考勤、课堂管理。**教师仅能查看本人所授班级** |
| **学校** | 本校学生的报名名单、上课与出勤情况 | 校园安全管理、教学秩序保障（只读查看） |
| **通联支付**（持牌支付机构） | 订单号、金额、支付状态、支付流水 | 收款、资金存管与分账结算 |
| **服务机构以外的关联主体** | 见第〇条 | 天府通为处理者本身，萃雅为受托方，二者不属于对外“共享” |
| **教育行政主管部门** | **优先以参与人数、班级数等汇总去标识化数据提供** | 法定监管报送义务；依法要求明细的依法提供 |
| **技术服务商**（云服务、短信等） | 履行服务所必需的最小信息 | 技术支撑，受保密与数据安全协议约束 |

**3.2 不共享的对象** 广告、营销、数据分析类第三方；**其他服务机构**（机构之间信息相互隔离，A 机构无法查看 B 机构班级的学生）。

**3.3 转让与公开披露** **不转让您的个人信息**，发生合并、分立、收购或资产转让时将告知接收方并要求其继续受本政策约束；接收方变更处理目的或方式的，重新征得您的同意。**不公开披露您与学生的个人信息**，法律法规要求或取得您单独同意的除外。

**3.4 无需另行同意的法定情形** 依《个人信息保护法》：为订立、履行您作为一方当事人的合同所必需；履行法定职责或义务所必需；应对突发公共卫生事件或紧急情况下保护生命健康财产安全所必需；在合理范围内处理您已自行公开的信息；法律法规规定的其他情形。

## 四、儿童个人信息专章（不满十四周岁）

> 本平台服务的学生多为儿童，其个人信息属于**敏感个人信息**。本章适用于儿童信息处理；**本章与本政策其他条款不一致时，以本章为准。**

**4.1 只能由监护人操作** **账号只能由具备完全民事行为能力的监护人注册。儿童信息由您以“添加学生”方式填写，儿童不参与注册、支付与课时确认等任何操作。您承诺对该儿童依法享有监护权。**

**4.2 同意的取得** **您添加学生信息、为该学生提交报名或支付、勾选同意本政策与《课程服务协议》，即构成您作为监护人对处理该儿童个人信息的明示同意。**

**以下情形将向您单独取得同意，不与其他授权捆绑：** 新增处理敏感信息类别；超出本政策所列目的使用；向本政策未列明的第三方提供；用于自动化决策；向境外提供。

**4.3 同意的撤回** **您可随时撤回同意**，撤回不影响撤回前已进行的处理活动的效力。**儿童信息是提供课程服务的必要条件，撤回将导致无法继续提供报名、考勤、教学记录等服务**，已报名课程按《课程服务协议》退费规则办理；会在您撤回前明确提示这一后果。

**4.4 收集范围（最小必要）**

| 信息项 | 环节 | 必要性 |
|---|---|---|
| 姓名 | 添加学生 | 点名考勤、班级名单、成果记录归属 |
| 就读学校、年级班级 | 添加学生 | 匹配课程范围与适合年级、编排班次 |
| 出勤状态 | 每节课教师签到 | 课时确认与销课结算依据、出勤异常告知 |
| 课堂记录与教师评语 | 每节课教师填写 | 教学过程留存、向您反馈学习情况 |
| 头像 / 课堂照片 | 添加学生 / 教师上传 | 非必需；课堂照片**仅向该班级学生监护人展示** |

**不收集儿童的**身份证号、人脸 / 指纹 / 声纹等生物识别信息、家庭住址、健康医疗信息、宗教信仰、行踪轨迹、通讯记录、儿童本人手机号。**不收集儿童的设备信息或行为日志用于画像分析**（设备与日志信息的收集对象是登录账号的监护人，用于安全风控）。

**4.5 严格禁止的使用** **承诺不将儿童个人信息用于：** 用户画像与标签化分析、个性化推荐；定向广告或任何商业营销；出售、出租或以其他方式牟利；自动化决策；训练人工智能模型（经完全匿名化且无法复原的统计数据除外）；与教学服务无关的其他目的。

**4.6 共享与披露** 按第三条共享清单执行。**天府通不获得任何儿童信息，通联支付不获得儿童姓名与教学记录。** 课堂照片与学习成果**仅在该班级学生监护人范围内展示，不对外公开、不用于平台宣传**，除经您单独书面同意外。**不向境外提供儿童个人信息。**

**4.7 专项安全措施** 内部按岗位最小化分配权限，仅课程运营、审核、客服等必需岗位可访问；**查询与导出操作生成审计日志可追溯到人**；批量导出须经审批；传输与敏感字段存储加密；非必要场景脱敏展示（如手机号显示为 138\*\*\*\*8888）；接触儿童信息的人员签署保密承诺并接受专项培训。**服务机构及其教师访问儿童信息，须签署数据处理协议并受上述约束。**

**4.8 删除权** **出现以下情形，您可要求删除儿童个人信息，将及时处理：** 处理目的已实现或不再必要；您撤回同意；违法违约处理；该儿童不再使用服务或您删除该学生 / 注销账号；服务终止。**法定保存期限未届满或删除技术上难以实现的，停止除存储与必要安全措施之外的处理。**

**4.9 身份核验** **为防止儿童信息被冒领或不当泄露，在响应查阅、复制、删除、转移等请求前将核验您的监护人身份**（注册手机号验证，必要时要求提供监护关系证明）。核验不通过的，有权拒绝并说明理由。

**4.10** 已满十四周岁未满十八周岁的未成年人个人信息，按法律法规关于未成年人个人信息的规定处理，并参照本章采取相应保护措施。

## 五、存储与安全

**5.1 存储地点** 信息存储于**中华人民共和国境内**。如需跨境提供，将依法履行安全评估程序并另行征得同意；**儿童个人信息不向境外提供**。

**5.2 存储期限**

| 类型 | 期限 |
|---|---|
| 账号与学生信息 | 账号存续期间；删除该学生或注销账号后 15 日内删除或匿名化 |
| 交易与订单记录 | **自交易完成之日起至少 3 年**（《电子商务法》） |
| 考勤与课堂记录 | 结课后 3 年，用于教学质量追溯与退费争议处理 |
| 日志信息 | **不少于 6 个月**（《网络安全法》） |

**超过期限的，删除或匿名化处理。**

**5.3 安全措施** 传输与存储加密、权限分级控制、操作日志审计、定期安全评估、员工保密培训。

**5.4 安全事件** **发生或可能发生个人信息泄露、篡改、丢失的，立即启动应急预案并采取补救措施，按规定告知您并向监管部门报告**，告知内容包括事件情况、可能影响、已采取措施与您可采取的防范建议。

## 六、您的权利

**6.1** 可通过家长端“我的—客服与售后”或第八条联系方式向天府通行使：**查阅、复制**（索取信息副本）；**更正、补充**（合作学校名单为平台入库数据，变更学校请通过客服办理转学流程）；**删除**（见 4.8）；**撤回同意**；**限制处理**（争议核实期间）；**注销账号**；**要求解释处理规则**；**转移**（符合法定条件时）。

**6.2 一个入口，统一受理** **您无需分别向天府通、受托运营方或服务机构提出请求。** 通过上述任一渠道提交后由平台统一受理，涉及服务机构的部分由平台协调处理。

**6.3 响应时限** 核验您的身份后 **15 个工作日**内响应，情况复杂需延长的将说明理由。**不因您行使权利收取费用**，但对不合理的重复请求可收取必要成本。

**6.4 可能拒绝的情形** **与履行法定义务冲突；直接关联国家安全、公共安全；有充分证据表明您存在恶意或滥用权利；响应将损害他人合法权益；涉及商业秘密。拒绝时将说明理由。**

**6.5 注销提示** **注销前请先完成已报名课程的相关事宜（含退费申请）。注销不可恢复，注销后无法查询历史订单与教学记录。**
