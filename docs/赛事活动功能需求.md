# 赛事活动功能需求

## 目标与入口

- 首页胶囊区增加「赛事活动」入口；其他平台投放赛事海报时，可直接链接到本平台的赛事详情路由 `#/contest/luxun-18`。
- 赛事列表当前只展示「第十八届鲁迅青少年文学大赛」。点击卡片查看详情。
- 本平台仅展示赛事信息，不采集报名资料，不判断报名成功，也不限制报名次数；一切报名结果以赛事官网为准。

## 赛事详情

- 展示名称、简介、主办单位、参赛对象、免费说明、报名时段、赛程和注意事项。
- 底部「立即免费参赛」打开赛事官网，按钮下提示「报名将在官方赛事平台完成」。注册、报名、作品上传、晋级确认及成绩查询均由官网完成。
- 赛事详情底部的「推荐课程」由后台逐个赛事配置。配置了课程才显示整个板块；没有配置时不显示。
- 推荐课程卡片展示封面、标题、作者、价格及缤果平台标识。已配置单本书链接的卡片可点击整张卡片，直接打开缤果详情页；未配置链接的课程仅展示，并提示购买渠道待开放。当前价格为模拟价格，正式价格由后台配置，以缤果实际售价为准。

## 我的课程

- 「我的」新增「我的课程」，通过「已购课程／数字教材」标签切换。已购课程包括已缴费托管中及已结算的课程，不包括待支付或已取消订单；点击课程进入对应的安排或成果页。
- 仅展示缤果回传的已支付订单，至少包含书目 ID、订单号、支付时间和状态；未回传时显示空状态，不推断用户已经购买。
- 当前仓库是无后端的静态 Demo。前端预留 `window.FutureEduDigitalBooks.receivePaidOrders(records)` 作为订单接入点，正式上线需由可信服务端校验缤果订单、关联平台学生账号，再向前端提供记录。前端不依据跳转或返回页面生成订单。

## 当前内容及待接入项

- 后台新增「赛事活动管理」，按当前家长端的列表封面、详情顶部、赛事信息、赛程、报名须知、官方报名入口和推荐课程配置赛事。支持创建、编辑、排序、预览、保存草稿、发布及下架。赛事封面与推荐课程封面均通过上传图片配置，分别建议 1200 × 675 像素（16:9）及 720 × 990 像素（8:11）；上传后裁剪、压缩并保存在当前浏览器。推荐课程配置位于表单最下方。
- 旧「赛事评审中心」及独立「赛事推荐课程」从后台菜单隐藏，原有逻辑保留。新管理使用单独的浏览器本地配置，家长端只展示已发布赛事；跨设备共用配置仍需服务端接口。

- 赛事文案取自用户提供的《鲁迅青少年文学大赛介绍（内部资料）》；赛程如有变化，以赛事官网为准。
- 官方报名链接：`https://www.luxunwenxue.com/`。
- 当前后台预置用户提供的缤果单本书链接，书目 ID 为 `516`。缤果公开接口显示其标题为「全国中小学生海洋文化创意设计大赛（白名单）AIGC赛训课」，作者字段为空。该书与鲁迅青少年文学大赛主题不符，正式投放前需在后台替换成实际配套课程。
- 为双课程展示增加「文学写作与作品赏析」模拟书目，配套封面与价格 ¥199.00 均为样例；尚无对应缤果单本书链接，因此暂不提供购买跳转。
- 待提供：正式推荐书目的单本书链接；缤果购买订单回传接口与账号／学生关联规则；外部平台赛事海报及其投放配置。
